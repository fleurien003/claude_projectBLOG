# /done 끝난 세션 마무리

`/save`는 다른 기기에서 이어서 하려고 중단 지점을 남긴다. `/done`은 남길 중단 지점이 없을 때 쓴다. 할 일 파일에 `## 이어서 할 곳`을 쓰지 않는다.

## 순서
1. **정말 끝났는지 확인**: 이 세션 일에 남은 단계(사용자 결정 대기, 확인 못 한 것 빼고)가 있으면 멈추고 "이어서 할 게 남아서 `/save`로 하겠습니다"라고 한 줄 알린 뒤 `/save` 순서로 한다.
2. **할 일 파일 정리**(파일 찾는 순서는 `/save`와 같음): 끝난 일은 지우고, `## 이어서 할 곳`에 이 세션 몫이 있으면 지운다(다른 세션 몫은 그대로). 기록할 결과가 있으면 그 파일의 진행 목록에 한 줄. ⚠️미확인이나 사용자가 눈으로 볼 것이 있으면 그 줄에 남긴다.
3. **전체용 CLAUDE.md 맞추기**: `/save` 3번과 같다.
4. **배포**: 이 세션에서 배포 대상(서버, 사이트) 코드를 바꿨고 아직 안 냈으면 배포한다. 명령은 그 프로젝트에서 찾는다(CLAUDE.md·README·TASKS 안내, `package.json`의 deploy 스크립트, `wrangler.jsonc`가 있는 폴더면 그 폴더에서 `npx wrangler deploy`). 바뀐 게 없거나 배포 대상이 아니면 건너뛴다. 배포 뒤 확인 주소(`/health` 등)가 있으면 열어 본다. 실패하면 멈추고 알린다(push까지는 한다).
5. **커밋하고 push**: `/save` 4번과 같다. 원격과 로컬이 같은지 확인한다.
6. 답은 "내 결정이 필요한 것 / 바꾼 것 / 알아낸 것"으로 짧게 쓰고, 배포했으면 버전 번호를 적는다. 마지막 줄은 "이어서 할 일 없음, `/go` 필요 없음".
7. 답 끝에 이 세션을 보관한다(`archive_session`, session_id `"self"`; 도구가 있을 때만). push나 배포가 끝나지 않았거나 내 결정을 기다리는 중이면 보관하지 않는다.

## 하지 않는 것
- 남은 일이 있는데 `/done`으로 닫기
- 이 세션에서 안 바꾼 것까지 배포하기
