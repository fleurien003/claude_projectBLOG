## 노트북 옮겨가며 작업하는 법
1. 작업 시작 전: `git pull origin main`
2. 대시보드 내용은 아티팩트 계정에 그대로 남아 있어서, **어느 노트북에서 열어도 데이터는 동일**합니다. 이 저장소의 파일은 "소스 백업 + 버전 기록"용입니다.
3. 대시보드를 고칠 때: `dashboard/index.html`을 고친 뒤 같은 아티팩트 주소로 다시 발행(republish)합니다. 새 주소를 만들지 않습니다.
4. 다른 노트북에서 대시보드를 먼저 고쳤다면, 저장소 파일이 옛날 버전일 수 있습니다. 고치기 전에 아티팩트를 먼저 읽어와서 `dashboard/index.html`을 최신으로 맞춥니다.

## 주의
- 데이터(체험단 기록, 초안, 발행 주소)는 이 파일이 아니라 아티팩트 데이터베이스에 저장됩니다. 파일만 복원해도 데이터는 따라오지 않습니다.
- 초안 자동 작성(`sample`)은 claude.ai에서 대시보드를 열었을 때만 동작합니다.
