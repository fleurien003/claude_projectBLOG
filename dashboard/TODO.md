## 🔵 만들다 만 기능

### 1. 홈피드형 템플릿이 연결 안 됨 (가장 큰 미완성)
- DB에 `h_travel` `h_celeb` `h_finance` `h_ott` 4개가 있고 📚 템플릿 화면에도 뜸 (`TPL_GROUPS`에 '홈피드형' 포함)
- 그런데 `buildFeedPrompt()`는 템플릿을 **한 번도 참조하지 않음.** 규칙이 전부 JS에 하드코딩
- 결과: 템플릿 화면에서 홈피드형을 고쳐도 초안에 반영 안 됨
- `kurly_pick` 카테고리는 대응 템플릿(`h_kurly`) 자체가 없음

> 홈피드 에디터의 업로드 전 점검 · 소주제별 복사는 **필요 없음** (2026-09-21 확인). 체험단 상세에만 둡니다.

### 2. 자잘한 잔여물
- `homeRankState` — 엘리먼트만 있고 JS에서 한 번도 안 씀 (문구 고정)
- `initDetail(id, isNew)`의 `isNew` — 해시에 `?`가 있어야 동작하는데 그런 해시를 만드는 코드가 없음 (죽은 경로)
- `photo_folder` — 28건에 값이 있고 링크로 보여주기는 하는데, `FIELDS`에 없어서 **대시보드에서 입력·수정할 방법이 없음**
- 홈 상단 4칸 중 `write`/`post`/`week`는 클릭해도 스크롤만 되고 이동은 `due`만 동작
- `campaigns` 컬렉션에 템플릿 문서 1건이 섞여 들어감 (`3db17c68a33d8112a88cff30dc254e54`, 이름 "판매형 - 여행(명소)") → 체험단 목록에 유령 카드로 보임
- 체험단 4건이 `status` 빈 문자열 (잇쇼니라멘 · 아이쁨 · 한결우동&모밀 · 유소바) → "상태 미정"으로 표시
