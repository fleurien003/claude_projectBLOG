## 2. 확정 규칙 (2026-09-22 재확정)

- **글의 맨 첫 문장은 한 문장만 단독으로.** 도입부 첫 줄에 다른 문장을 붙이지 않는다.
- 그다음부터는 문단 구조. **한 문단은 문장 최대 2개.** 1개짜리 문단도 괜찮고, 3개 이상은 안 된다.
- 줄 간격은 딱 두 가지뿐이다.
  - **문단과 문단 사이 = 엔터 2번 (빈 줄 1개)**
  - **소주제와 소주제 사이 = 엔터 4번 (빈 줄 3개)**
- 소주제 줄 앞에는 빈 줄 3개, 소주제 줄과 첫 문단 사이에는 빈 줄 1개.
- 문장 하나 길이는 공백 포함 **45~90자**가 기본. 20자짜리 단문만 나열하지 않는다.
- 연결어미로 호흡을 길게: `~는데요` `~고요` `~다 보니` `~라서` `~어서` `~지만`
- 종결어미는 섞어 쓴다: `-더라고요` `-했어요` `-좋았어요` `-거든요` `-것 같아요` `-고요`
  (같은 어미 3연속 금지)
- 한 문단 = **상황 → 내가 한 행동 → 느낀 점** 순서
- 문단마다 한두 번은 감탄·혼잣말로 생기를 준다.
  예) `셀프바에 밥이 따로 준비되어 있다는 사실! 무료로 추가할 수 있어서 더 좋더라고요!`
- 📍☎️🕖🚘 정보 줄만 예외로 빈 줄 없이 한 줄씩.
- **`1. 위치 및 주차` 소주제는 📍 줄로 바로 시작한다.** 📍 위에 상호명·주소를 한 번 더 적거나 안내 문장을 넣지 않는다. (2026-09-22 확정)

## 3-1. 어투 규칙 (2026-09-22 확정)

르나는 **말하듯이** 씁니다. 글로 쓴 티가 나는 딱딱한 표현은 구어체로 내립니다.

| 상황 | 문어체 (X) | 구어체 (O) |
|---|---|---|
| 추측·동의 구하기 | ~할 거예요 / ~것 같아요 / ~되겠어요 | **~겠죠 / ~죠** |
| 강조 부사 | 완전히 / 매우 / 상당히 / 굉장히 | **완전 / 진짜 / 너무** |
| 딱딱한 서술 | ~하는 개념으로 생각하시는 게 맞아요 | **~라고 생각하시면 돼요** |
| 권유 | ~해보셨으면 해요 | **~해보세요** |
| 서술체 혼입 | ~하시면 됩니다 | **~하시면 돼요** |

**문장 끝 여운**은 `~` 와 `!` 를 섞어 씁니다.
- 물결표 `~` — 부드럽게 풀 때 (예: "완전 달랐어요~")
- 느낌표 `!` — 확실히 추천하거나 감탄할 때 (예: "꼭 넣어두세요!")
- **글 한 편에 합쳐서 3~4번까지.** 남발하면 가벼워 보입니다.

> 원래 먹고 나서 공기밥까지 추가해볼까 했었는데 이날은 양이 많아서 결국 밥 추가는 포기했어요. 평소 라멘 한 그릇으로는 부족하다고 느꼈던 분이라면 오히려 만족도가 높을 것 같아요.
