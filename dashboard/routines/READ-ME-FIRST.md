# 자동화 프롬프트 — 승인이 필요한 변경

## ⚠️ "블로그 글쓰기 자동화"는 제가 못 고칩니다

이 Routine은 **은아님 컴퓨터(이름: 으나)에 묶여 있어서**, 프롬프트를 바꾸려면
**그 컴퓨터와 연결된 대화에서 은아님이 직접 승인**해야 합니다.
(이름·스케줄·켜기/끄기는 승인 없이 바뀝니다. 프롬프트만 승인이 필요해요.)

새 프롬프트 전문은 `blog-writing-automation.md`에 넣어뒀습니다.

### 적용하는 방법 (둘 중 하나)
1. **으나 컴퓨터**에서 Claude 데스크톱 앱을 열고 → 그 대화에서 저한테 "블로그 글쓰기 자동화 프롬프트 바꿔줘"라고 요청 → 승인
2. 으나 컴퓨터의 Claude 데스크톱 앱에서 **작업(Routine) 목록 → 블로그 글쓰기 자동화 → 프롬프트 직접 수정**

> ❌ 이 Routine을 지우고 새로 만들면 안 됩니다. 실행 기록과 연결된 컴퓨터 정보가 사라집니다.

## 이번 변경에 담긴 내용 (3가지)

1. **소제목 번호를 `1. 2. 3.`으로** — ①②③ 금지 (2026-09-21 확정)
2. **초안은 무조건 프롬프트 기반으로** — 프롬프트 없이 기본 정보만으로 쓰지 않음
3. **위치 정보 덮어쓰기 버그 수정** ← 제일 중요
   > 프롬프트의 1⃣ 소주제에 📍☎️🕖🚘 값이 이미 적혀 있으면 그 값을 본문에 그대로 옮겨 쓴다.
   > "방문 전 매장 문의"로 덮어쓰지 않는다. 그 표현은 `[확인 필요]`로 비어 있고 이번 회차에도
   > 확인에 실패했을 때만 쓴다.

   (위드뮤직실용음악학원 건에서 프롬프트에 주소·전화·영업시간이 다 있었는데
   본문이 전부 "방문 전 매장 문의"로 나간 사고가 실제로 있었습니다.)
