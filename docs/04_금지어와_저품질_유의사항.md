# 금지어와 저품질 유의사항 (2026-09-22)

출처는 은아님이 주신 구글 문서 두 건이다.
1. 저품질 키워드 루머 및 저품질/불법 포스팅 유의사항
2. 약손명가 콘텐츠 내 사용불가 단어 리스트

검사는 `tools/banwords.py` 로 한다.
```
python3 tools/banwords.py <초안.txt> --type massage   # 안마·에스테틱
python3 tools/banwords.py <초안.txt> --type derm      # 병원·의원
python3 tools/banwords.py <초안.txt>                  # 공통만
```

## 1. 업종별로 조심할 것

| 업종 | 핵심 |
|---|---|
| **국내 마사지샵** | **아래 치환표의 단어만 안 쓰면 된다.** 업소가 어떤 형태인지는 확인하지 않는다 (2026-09-22 르나 확정). 해외 아로마 마사지 글에는 이 규칙이 적용되지 않는다 |
| **병원·의원** | 후기 글 자체가 불법 소지. 병원명·의사명을 가리고 비밀댓글로 안내하는 방식이 그나마 안전. **추천·할인·보증·인증·광고** 다섯 단어 금지. 시술 전후 촬영도 원칙적으로 금지 |
| **의약·건기식** | 효과·효능은 **원료에만** 쓴다. 추출물이 효과가 있는 것이지 그게 든 화장품이 효과가 있다고 쓰면 안 된다. **"개선"** 표현 금지. 질병명으로 치료를 연상시키지 말 것 (여드름 → "피부가 매끈한 느낌이다") |
| **음식** | 영업등록만 확인되면 OK. 식품안전나라에서 검색. 등록 안 된 농장·공장은 쓰지 말 것 |
| **이사·에어컨 청소** | 키워드는 문제없다. **남의 사진을 받아쓰는 기자단식 글**이 저품질의 진짜 원인 |
| **안경·렌즈** | 온라인 배송 불법. 2024-12-24 판결로 **온라인 주문 후 오프라인 픽업도 불법** |
| **타투·눈썹문신·반영구** | 의료기관 밖에서는 불법 |
| **카드·보험·은행** | 광고심사필 필요. "4% 인상"이 아니라 "세전 4%p 인상". 사업자 등록 없는 보험비교업체 주의 |
| **대출** | 카드깡·소액대출·기프트카드·청소년 대출은 불법 업체. 신혼부부 전세대출 같은 정보성 글은 괜찮다 |
| **운전연수** | 경찰청 등록 학원만. 내 차로 받는 사설 연수는 도로교통법 위반 |

## 2. 바꿔 쓸 말 (안마·에스테틱)

약손명가 리스트 기준. **이 업종 글에서는 예외 없이 적용한다.**

| 쓰지 말 것 | 대신 |
|---|---|
| 마사지 · 맛사지 · 안마 · 경락 · 지압 · 압 · 악력 · 누르기 · 주무르기 · 치료 · 교정 · 시술 | **관리** |
| 통증 · 건강 · 뼈 · 혈 · 림프선 · 림프 · 순환 · 부종 · 노폐물 · 독소 · 배출 · 신진대사 | **쓰지 않는다** |
| 뼈관리 · 근육관리 · 스트레칭 | **쓰지 않는다** |
| 혈액순환 | 쓰지 않는다 |
| 혈행개선 | 피의 흐름을 도와주는 |
| 뭉친 · ~를 풀다 | **긴장이 풀리는 느낌이다** |
| 시원했다 · 아팠다 · 뻐근하다 · 풀어주다 | 사용 자제 |
| 스트레스 | 긴장된 |
| 부종제거 · 붓기제거 | 붓기관리 |
| 얼굴 축소 | 작은 얼굴로 관리 |
| 안면비대칭 | 얼굴 불균형 |
| 틀어진 | 바르지 않은 |
| 피부재생 | 피부결이 개선되는 |
| 흉터제거 | 흉터관리 |
| 셀룰라이트 제거 | 셀룰라이트 관리 |
| 골반을 바로 잡아준다 | 불균형한 바디라인의 균형을 관리한다 |
| 다리를 교정 · 일자다리로 만들어 준다 | 다리라인을 관리한다 |
| ~효과가 있다 · 효과를 준다 | ~에 도움이 되었다 |
| 만들어 드린다 · 해준다 | 관리해드린다 · 가꿔드린다 |
| 책임제 | 고객과의 약속 |
| 요요없는 | 요요 관리로 |
| 골기테라피 · 골기 마사지 | 약손테라피 |
| 대사물질 | 볼록한 라인 |
| 뱀부 사진 | 쓰지 않는다 |
