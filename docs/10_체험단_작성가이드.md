## 문체·줄바꿈·어투 (2026-09-22 재확정)

자세한 근거와 치환표는 `dashboard/STYLE-GUIDE.md`.

**줄바꿈**
- **글의 맨 첫 문장은 한 문장만 단독으로** 씁니다. 도입부 첫 줄에 다른 문장을 붙이지 않습니다.
- 그다음부터는 문단 구조. **한 문단은 문장 최대 2개** (1개도 괜찮고, 3개 이상은 안 됩니다).
- 줄 간격은 두 가지뿐입니다.
  - 문단과 문단 사이 = **엔터 2번** (빈 줄 1개)
  - 소주제와 소주제 사이 = **엔터 4번** (빈 줄 3개)
- 소주제 줄 앞 빈 줄 3개, 소주제 줄과 첫 문단 사이 빈 줄 1개.
- 문장 하나는 공백 포함 45~90자가 기본입니다. 짧게 끊지 않습니다.
- 📍☎️🕖🚘 정보 줄만 예외로 빈 줄 없이 붙여 씁니다.
- **`1. 위치 및 주차` 소주제는 📍 줄로 바로 시작합니다.** 📍 위에 상호명·주소를 한 번 더 적거나 안내 문장을 넣지 않습니다.

**어투 — 말하듯이 씁니다. 고치는 건 "어미"가 아니라 "글로 쓴 티"입니다.**

고칠 것은 네 가지뿐입니다.
1. 강조 부사 `완전히 / 매우 / 상당히 / 굉장히` → **`완전 / 진짜 / 너무`**
2. 합쇼체 혼입 `~합니다 / ~됩니다 / ~입니다` → **`~해요 / ~돼요 / ~이에요`**
3. **`-겠어요` → `-겠죠`** (이 어미 하나만)
4. 늘어진 번역투는 풀어서 (`~하는 개념으로 생각하시는 게 맞아요` → `~라고 생각하시면 돼요`)

**건드리지 않습니다 — 르나가 실제로 쓰는 말입니다.**
- `~거예요` 그대로 ("마음에 드실 거예요"를 "드시겠죠"로 바꾸지 않습니다)
- `~것 같아요` 그대로 ("기억에 남는 것 같아요"를 "남죠"로 바꾸지 않습니다)

**절대 쓰지 않는 말**
- **`와닿다`** — 어떤 어미를 붙여도 금지. "제일 반가우실 거예요", "마음에 드실 거예요"처럼 구체적으로.

**도입부 — 날짜를 쓰지 않고, 마지막 문단은 훅으로 끝냅니다.**
- **방문 날짜 금지.** "9월 17일 오후에 다녀온" 같은 표현을 쓰지 않습니다. (르나 발행글 6편 실측 결과 0편)
- 도입부 마지막 문단은 다섯 유형 중 하나로 끝냅니다 — ① 결과 스포일러 ② 목차 예고 ③ 판정 선언 ④ 이유 예고 ⑤ 독자 지목.
  문장 예시와 업종별 궁합은 `dashboard/STYLE-GUIDE.md` 3-2 참고.
- 같은 업종에서 연속으로 같은 유형을 쓰지 않습니다.

**문장 끝 여운**
- `~` 와 `!` 를 섞어 쓰되 **글 한 편에 합쳐서 3~4번까지만.** 남발 금지.
- 개수는 `tools/banwords.py` 가 ⚠️ 말투 줄로 세어줍니다.

이미 쓴 초안은 도구로 재정렬합니다.
```
python3 tools/reflow.py <초안.txt> -i
```

## 체험단 글 작업 순서 (2026-09-21 확정 — 토큰 절약 포함)

**0단계가 제일 중요합니다. 받은 것·후기를 먼저 읽고 시작합니다.**

1. **받은 것 · 후기 확인** — 대시보드의 "받은 것"과 "후기" 칸을 가장 먼저 읽는다.
   둘 중 하나라도 적혀 있는데 상태가 '방문 완료' 앞 단계면 **상태를 '방문 완료'로 바꾸고** 시작한다.
2. **재료 수집** — 0단계에서 확인한 *받은 것*을 검색어에 넣어 `/research`를 돌린다.
   지역을 아는 경우 처음부터 `place=업체명 지점명`으로 한 번에 부른다. (지점 찾느라 두 번 부르지 않는다)
3. **재료 압축** — 기본은 후기 목록의 제목·요약. **가격을 위해 블로그 포스팅 1편만 읽는다.** (2026-09-22 수정)
   ```
   python3 tools/digest.py <research.json> --got "국밥정식,찰순대"
   ```
   `--got`에 받은 것을 넣으면 그 메뉴를 다룬 남의 후기가 맨 위로 온다.
   - 본문 5편을 읽으면 1만 자가 대화에 실리고, 그 대화는 턴마다 다시 전송된다.
   - 요약만으로도 위치·영업시간·주차·분위기·맛 포인트는 충분히 나온다.
   - 다만 **가격은 요약에 안 나온다. 가격은 남의 블로그 포스팅 1편을 읽어서 가져온다 (아래).**

### 가격은 블로그 포스팅 1편에서 읽는다 (2026-09-22 확정)

가격은 글의 필수 정보인데 후기 요약에는 안 나오고, 네이버·카카오 공식 API에도
메뉴·가격 필드가 아예 없습니다. (확인 완료 — 두 API 모두 위치 정보만 돌려줌)

그래서 **남이 쓴 블로그 포스팅을 딱 1편만 읽습니다.**

- 받은 것(메뉴·서비스명)이 제목이나 요약에 나오는 글 중에서 **1편**을 고른다.
- 그 한 편에서 가격뿐 아니라 **메뉴 구성·양·분위기 묘사까지 같이 건져** 쓴다.
  (이래서 사진보다 낫다 — 후기 내용도 같이 풍성해진다)
- **2편째는 읽지 않는다.** 폐기한 "본문 5편 통독"(약 13,000토큰)으로 돌아가지 않기 위한 상한선이다.
- 1편으로도 가격이 안 나오면 **가격 줄을 빼고 쓴다. 추측 금지.**
- 토큰은 1편에 2,000토큰 안팎. 캠페인 1건 예산(1.5만~2만) 안에 들어온다.

> ⚠️ **2026-09-21에 "메뉴판 사진 1장을 OCR로 읽는다"로 잘못 적어뒀던 규칙입니다.**
> 은아님이 "블로그 포스팅 **1개**"라고 하신 것을 제가 "사진 **1장**"으로 읽은 착오였습니다.
> 실제로 권문정플라워에서 이 방식이 실패했습니다 — 사진이 업로드 직후라 OCR 색인 전이었고,
> 꽃집·미용실처럼 **메뉴판 사진 자체가 없는 업종**도 많습니다.

~~사진은 보조 수단 (캠페인 사진 폴더의 메뉴판·영수증 참고)~~ → **2026-09-24 르나 결정으로 삭제.** 템플릿 18개(v17)에서도 뺐습니다.

### 내 후기가 짧을 때
르나의 후기 한두 줄을 **뼈대**로 삼고, 같은 메뉴를 먹은 남의 후기에서

### 토큰 관리
- 체험단 1건 ≈ 1.5만~2만 토큰 (본문을 읽던 예전 방식은 3만~4만)
- 대화는 턴마다 통째로 다시 전송되므로 **읽은 양 × 남은 턴 수**가 실제 비용이다.
  긴 원문은 파일로 받고 요약만 대화에 올린다.
- 캠페인 하나를 끝내면 새 대화로 넘어가는 편이 싸다.
- **실측 (2026-09-24, 마감 3건)** : 대화에 새로 쌓인 양 약 7.5만 토큰 = 건당 약 2.5만.
  그중 캠페인 140건 전체 목록 받기가 약 1.8만으로 제일 컸다 → **다음부터 `query` 로 마감일·상태를 걸러서 받는다.**
- **캠페인을 찾을 때 `list` 로 전체를 받지 않는다 (2026-09-24 르나 지적).** `out_dir` 로 받아도 결과에 140줄이 찍혀 1.8만 토큰이 든다.
  - 🔥 마감 탭 : `query` + `where: [["due","<=","오늘 날짜"]]` → 받은 뒤 포스팅 완료·진행안함만 빼면 된다
  - 이름으로 찾기 : `where: [["name","==", ...]]`, 상태로 찾기 : `where: [["status","==","방문 완료"]]`
  - `limit` 을 꼭 건다

## 금지어·저품질 (2026-09-22 확정)

자세한 내용과 치환표는 `docs/04_금지어와_저품질_유의사항.md`.
**초안을 올리기 전에 반드시 검사기를 돌립니다.**

```
python3 tools/banwords.py <초안.txt> --type massage   # 안마·에스테틱
python3 tools/banwords.py <초안.txt> --type derm      # 병원·의원
python3 tools/banwords.py <초안.txt>                  # 공통만
```

**지키는 방법은 단어를 안 쓰는 것뿐입니다.** 업소 형태를 따로 확인하지 않습니다. (2026-09-22 확정)

- **안마·에스테틱** — 마사지·안마·지압·경락·시술·치료·교정을 전부 "관리"로 바꾸고,
  통증·순환·뼈·근육·스트레칭 등은 아예 쓰지 않는다. 치환표는 문서 2번 항목.
- **병원·의원** — 병원명·의사명·위치·연락처를 쓰지 않고, 추천·할인·보증·인증·광고
  다섯 단어를 쓰지 않는다. 시술 전후 사진 자리도 만들지 않는다.
  **제목에 업체명을 넣는 규칙보다 의료법이 우선한다.**
  단 "내돈내산"은 이 글에서만 허용되며 **제목에 넣어도 된다.**
