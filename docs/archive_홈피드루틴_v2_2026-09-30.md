     med=statistics.median(base) if base else 0
     mad=statistics.median([abs(x-med) for x in base]) if base else 0

         if mad==0: return 0 if x==med else (10 if x>med else -10)

     elif score>=2.0: label='📈상승'

### 발행 창과 급등 게이트 (2026-09-23 르나 승인 — 과거 사건 13개·키워드 44개 실측)
판정 대상은 카테고리 일반어가 아니라 **이벤트 키워드**(작품 제목, 제도 고유명, 인물+아이템, 축제명, 시즌+품목). 기사 용어(○○대책·○○논란)가 아니라 사람이 검색창에 치는 말로 찾는다. 고유명 → 고유명+행동 → 고유명+궁금증 순으로 내려가고 `related`에 🔥가 있으면 다시 친다. 10회 미만+연관 0개는 죽은 표현. 소재당 조회 7회까지, 5회 쳐서 전부 10회 미만이면 그 소재는 버린다.

게이트 (카테고리 무관):
1. 🔥급등 / 🚀신규급등 → 발행 창 밖이어도 **채택**
2. 창 안인데 ➖평탄 → 제외
3. 📉피크 지남 → 제외
4. 월 1,000회 미만(⚪판정 보류) → 표현을 바꿔 다시 찾는다. 1,000~3,000회는 📈상승 이상(score 2.0 이상)일 때만 유효
5. 사건이 아직 앞에 있고 창이 안 열렸으면 지금은 내지 않는다(창 시작일에 낸다)
6. **1번 후보가 그 카테고리에 하나도 없을 때만** 📈상승이면서 월 검색량 50,000회 이상인 이벤트 키워드를 대신 채택 (2026-09-29 르나 승인. 50,000회는 근거 없는 판단값). `trend_note` 끝에 "(급등 후보 없어 상승+대량 채택)".

발행 창 (D = 사건일):
- 명절 선물(kurly_pick) D-14 ~ D-9 · 크리스마스 D-7 ~ D-3
- 연휴여행·국내여행(travel_issue) D-12 ~ D-5 · 연휴 해외여행은 게이트만
- 축제·꽃 명소(travel_spot) 개막 D-7 ~ D-1 — 축제 고유명으로 판정
- OTT 일괄 공개 D-1 ~ D+1 · 나눠 공개는 파트마다 게이트
- 재테크 신고 **시작일**·지급일 D-3 ~ D+5
- 연예·패션은 날짜 창 없음, 게이트만

`trend_note` 형식: "<이벤트 키워드> 월 N회 <아이콘> score=<점수> · 창 D-n" (창이 없는 카테고리는 "· 게이트만"). `main_keyword`는 이벤트 키워드를 공백 없이 글자 그대로, `keyword_volume`은 그 `total`.

### 훅 — 제목 뒤에 딱 하나 (2026-09-24 르나 승인, docs/07 리서치)
재료를 보고 위에서부터 처음 맞는 것.
1. D 숫자 — 본문이 여러 곳·여러 개를 나열할 재료면 개수 (`근교 4곳` `5가지`)
2. B 손해 피하기 — 마감·가격 인상·매진·인파처럼 놓치면 손해인 사실이 출처에 있으면 (`개막하고 가면 늦어요` `모르고 가면 손해`). 부정·손해 표현은 홈피드 제목에서만 허용되는 예외.
3. C 질문 — 사람마다 답이 다른 주제면 (`우리 집도 해당될까?`)
4. A 반만 말하기 — 그 외. 주제는 구체적으로, 답은 숨긴다 (`~했더니..` `~인 이유`)
- 훅 속 숫자·마감·사실은 출처에 있는 것만. 괄호 【】 [ ] ( ) 금지. 같은 카테고리 직전 카드와 같은 훅이면 다음 순위로. 고른 훅을 `hook_type`에 A·B·C·D로.
- 계절 소재 후보 달력(참고용): 벚꽃 3월 4주 · 물놀이 5월 4주 · 보양식 6월 4주 · 단풍 10월 1주 · 김장 10월 4주 · 스키장 11월 1주 · 크리스마스마켓 11월 2주. kurly_pick: 유튜브 쇼츠·인스타 릴스에서 뜨는 식품·살림템(타겟 30~40대 주부, 연예인 식단 포함), 후보 2~3개를 게이트로 비교해 🔥이면서 검색량 큰 쪽.

- 목록 밖이어도 채택: 여성 + 착장·제품·루틴이 특정됨 + 부정 프레임 아님 + 패션·뷰티로 자주 언급되는 사람 (정려원, 안소희, 이효리)
- 1순위는 **인스타그램에 올린 착장·아이템**. 그 외 공항패션, 데일리룩, 구체 제품이 있는 앰배서더, 다이어트·식단·운동, 피부관리·화장품, 헤어, 가방·주얼리·신발.
- 버린다: 잡지 커버·화보 소식, 제품이 특정 안 되는 소식(발탁·컴백·수상 단독), 논란·소송·정치·범죄·건강악화, 힙합·예능 캐릭터형, 신인·중소 아이돌 단체, 일반인.
- 사진 기사는 세지 않는다: 제목이 `[HD포토]`·`[포토]`·`[E포토]`·`[SC포토]`·`[Oh!쎈 컷]` 등 `[`로 시작하고 포토·컷이 들어간 것. 한 매체의 연속 기사는 1건으로 센다.
- 가격대: 실제로 살 수 있는 중저가(SPA·컨템포러리)와 명품이 좋다. 비싸기만 하고 화제성 없는 중간은 피한다.
- 열애·결혼·임신 같은 경사는 연예 전체에서 주 2건까지.
- 이벤트 키워드는 `인물명+아이템`(예: `장원영가방`).

### 중복 방지
`items`를 doc_id 날짜 접두사로 걸러 아래 기간만 `topic`을 비교한다. 같은 인물·작품·장소·제품이면 내지 않는다. celeb 14일 / travel_issue·finance 30일 / ott 90일 / travel_spot·kurly_pick 365일 (작년 주제를 또 쓰려면 각도를 완전히 바꾸고 trend_note에 적는다).

### 해시태그
`hashtags`: 이벤트 키워드 + related_keywords 중 **검색량이 확인된 것 30개**를 검색량 순으로. 항시 대형 키워드와 롱테일을 섞는다. 부족하면 연관 키워드로 1~2번 더 조회. 검색량 0이거나 조회 안 되는 조어는 넣지 않는다.

### 토큰 규칙
카테고리당 후보 3개까지만 본다. 검색 결과는 제목·날짜 위주로 보고 본문은 꼭 필요한 1건만 읽는다. 1단계 뉴스 발굴은 카테고리당 WebSearch 1~2회. 연예는 포괄 쿼리("연예인 인스타 착용", "셀럽 가방", "공항패션") 먼저 돌리고, 걸린 인물만 개별 검색. 이미지·스크린샷은 보지 않는다. 중계 서버 호출은 회차당 20회 이하. 검색어트렌드 직접 호출은 소재당 1회, 회차당 15회 이하.

### 보고
짧게 한국어로: 카테고리별 주제 한 줄씩(이벤트 키워드·판정·훅 포함) + 대시보드 링크. 카테고리를 건너뛰었으면 "➖평탄" 한마디로 뭉뚱그리지 말고, 실제로 시도한 키워드마다 검색량과 판정을 전부 적는다. 아무것도 못 냈으면 "쓸 만한 이슈 없음" 한 줄.

## ② 다른 주제 가져오기 v2 (요약)

②는 ①과 같은 발굴·게이트·제목 공식·훅·연예 필터·중복 방지·토큰 규칙(위 ① 본문)을 그대로 쓰고, 절차만 다르다.
- 매일 오후 2시(KST). 사람에게 묻지 않는다. **글(초안)은 절대 쓰지 않는다.** 노션은 쓰지 않는다.
- 1. `items` 에서 `status == "requested_new"` 인 문서를 query로 찾는다. **없으면 아무 말 없이 바로 종료.**
- 2. 있으면 각 문서를 같은 `category_key` 의 완전히 새 소재로 교체한다: `update` 로 topic/emphasis/twist/title_bait/hook_type/source_url/source_url2/image_links/trend_note/event_date/main_keyword/keyword_volume/hashtags 를 새 값으로, `status:'pending'`, `draft_content` 는 `{"__delete__": true}`. 읽은 version을 if_version 으로. 교체 전 주제는 `note` 에 "이전 주제: …" 한 줄.
- 3. 소재 고르는 규칙은 ①과 같다. 다만 ②에만 있던 보조 신호: `curl -sS -m 15 "https://trends.google.com/trending/rss?geo=KR"` (로그인 불필요, 실시간 10개 고정 티커라 주력 소스로 안 씀). 고른 후보가 여기 우연히 떠 있으면 trend_note에 "구글 트렌드 확인됨" 한 줄만 덧붙이고 없어도 무시.
- 3-1. (계속) 소재 고르는 규칙은 ①과 같다. 게이트를 통과하는 새 소재가 없으면 교체하지 말고 `note` 에 "대체 소재 없음 (날짜) — <시도한 키워드와 판정>" 만 남긴다.
- 4. 보고: 교체한 카테고리와 새 주제 한 줄씩(이벤트 키워드·판정·훅 포함) + 대시보드 링크.
