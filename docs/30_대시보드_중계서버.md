## 초안 쓰기 버튼 동작 (2026-09-22 수정)

상태를 `방문 완료`로 바꾸거나 "초안 쓰기"를 누를 때, **프롬프트가 없으면 먼저 프롬프트를 만들고
그 프롬프트로 초안을 씁니다.** 기본 정보만으로 바로 쓰지 않습니다.

- 확인창 버튼 문구 : ~~그대로 쓰기~~ → **`프롬프트 업데이트 후 쓰기`**
- 누르면 `writePromptNow()` 가 템플릿을 고르고 프롬프트를 쓴 뒤, 그 결과를 그대로 받아 초안을 씁니다.
- **프롬프트 만들기가 실패하거나 멈추면 초안도 쓰지 않습니다.** (규칙 없는 글이 나가는 걸 막음)

#### 어떻게 불리는가 — MCP 커넥터 (2026-09-23 확정)

**아티팩트는 `fetch()` 로 바깥을 못 부릅니다.** 2026-09-23에 화면에서 직접 확인했습니다 —
우리 중계 서버도, `api.github.com` 도 전부 `TypeError: Failed to fetch` 였습니다.
샌드박스가 외부 호출을 통째로 막습니다. **서버 문제가 아니었습니다.**

아티팩트가 바깥에 닿는 통로는 **뷰어의 claude.ai 커넥터 하나뿐**입니다.
그래서 중계 서버를 MCP 서버로 만들어 커스텀 커넥터로 등록했습니다.

```
커넥터 이름 : naver-blog-helper        ← 코드가 이 이름으로 찾는다. 바꾸면 안 됨
주소        : https://naver-blog-helper.onrender.com/mcp/<MCP_SECRET>/
도구        : keyword_volume · place_lookup · blog_read · news_mentions · trend_scan  · blog_search · blog_feed (2026-10-01 배포)
```

**같은 통로로 구글 캘린더도 부릅니다** (2026-10-01, v87). 아티팩트 `capabilities.mcp.servers` 선언:
`naver-blog-helper` [keyword_volume, place_lookup, blog_read, news_mentions, blog_search, blog_feed] + `Google Calendar` [create_event, update_event].
재발행할 때 `capabilities`를 생략하면 저장된 선언이 그대로 유지되고, 다시 넘기면 **전부 적어야** 합니다(빠진 서버는 빠짐).
캘린더 동작은 `docs/40` "대시보드가 직접 등록합니다".

### 캠페인 링크 읽기 `/page` (2026-09-30 배포, 10-01 실측)
| 플랫폼 | `/page` 결과 | 비고 |
|---|---|---|
| 후기업 | 읽힘 | 내부 API 핸들러 |
| 리뷰노트 | 실패 (SPA) | 내부 API 주소 필요 — 브라우저 F12 → Network 캡처 대기 |
| 레뷰 | 실패 (SPA) | 코드의 `api.weble.net` 경로는 미검증 추정, 실제 안 맞음 |
| 강남맛집 | 접속 시간 초과 | Render(해외) IP를 막는 것으로 보임 ⚠️미확인. **10/2: 렌더링 프록시 `r.jina.ai`(HTML 형식)로 읽힘 → 루틴 v3.5가 직접 사용, 윈도우 불필요** |
| 미스터블로그 | 로그인 필요 | 불가 |

- 프로토콜은 직접 짜지 않고 **FastMCP** 를 씁니다 (`stateless_http=True`, `json_response=True`).
- 도구는 기존 HTTP 라우트를 그대로 감싼 것이라 **어느 쪽으로 불러도 같은 답**이 나옵니다.
- 호출은 **뷰어 자격증명**으로 나가고 페이지 코드는 토큰을 보지 않습니다.
- 대시보드가 직접 부르므로 **Claude 토큰 0**. (제가 채팅에서 부르면 조회당 ~300토큰)

**실패는 코드별로 다르게 안내합니다.** 하나로 뭉뚱그리면 정작 화면을 살릴 행동이 안 보입니다.
`server_not_connected`(커넥터 추가) · `needs_reauth`(재연결) · `not_in_manifest`(허용 누르기) ·
`server_unavailable`(잠시 뒤 재시도, 1회만 자동) 등. `retryable` 표시된 것만 자동 재시도합니다.

> ⏳ **첫 조회가 느리거나 한 번 실패하는 건 정상입니다.** Render 무료 플랜이 15분 놀면 자고,
> 커넥터 연결 제한이 30초라 깨는 도중이면 실패합니다. **한 번 더 누르면** 됩니다.

#### 중계 서버 보호 (2026-09-23)

| 대상 | 방법 | 이유 |
|---|---|---|
| MCP | **경로 비밀값** `MCP_SECRET` → `/mcp/<값>/` 로만 열림 | 커스텀 커넥터의 고정 헤더 인증은 아직 베타라 화면에 없을 수 있음 |
| HTTP 라우트 | **IP 기준 시간당 120회** (`RATE_PER_HOUR`) | 토큰을 걸면 클로드 세션에서도 못 불러 작업이 막힘 |

`MCP_SECRET` 을 바꾸면 **커넥터 주소도 같이 고쳐야** 합니다. 안 고치면 404가 됩니다.
비밀값은 Render 환경변수로만 넣습니다. 코드에도 대화에도 남기지 않습니다.
