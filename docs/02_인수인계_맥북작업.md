## B. 결정 사항 (문구 그대로 + 이유)

- 키워드 배치 설명 같은 메모는 글에 출력하지 않음(복붙용).
체험단
- 목적 중심(가게에 가고 싶게 / 의료기관은 댓글 유도).
- 후기를 "후기에서 ~라고 해요"로 옮기지 말고 1인칭 경험으로.
- 협찬·체험단·체험·체험권·제공·경제적 대가·체험 가능 시간 등 조건 이야기 금지.
- 본문 공백 포함 2,000자 이상, 해시태그 30개(검색량 확인된 키워드만, 조어 금지). 네이버 플레이스 리뷰 300자 안팎.
- 제목: 업체명 필수, 같은 단어 중복 금지, 맨 앞 롱테일 키워드 + 작은 키워드 + 업체명. 롱테일 키워드 본문 7회 이상.
- 해시태그는 검색량 많은 키워드 중심, 그 키워드의 연관검색어로 구성.
- [확인 필요] 남발 금지, 모르면 "방문 전 매장 문의".
- 의료기관: 병원명·위치·연락처 쓰지 않음.
- 전화번호는 업체 대표번호. 캠페인 담당자 번호는 안 씀.
홈피드

- 1,300~1,700자, 소주제 3~5개, 해시태그 30개(카드의 hashtags), main_keyword 5회 이상.
- 제휴 링크 최대 3회, 링크만 있는 소주제 금지. 마무리는 내용에 맞게 자연스럽게. 수수료 안내 문구는 안 씀(르나 전용 스티커 있음).

- 사진 기사([HD포토] 등) 제외.
- 중복 방지: 연예 14일 / 여행이슈·재테크 30일 / OTT 90일 / 여행명소·컬리 365일.
